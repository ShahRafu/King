# King Assistant (Project Skeleton)

সংক্ষিপ্ত: এটি King Assistant-এর Android (Kotlin + Jetpack Compose) প্রথম ড্রাফট স্কেলিটন। এখানে UI, voice-auth scaffold, RobotEngine scaffold, secure storage scaffold এবং ডকুমেন্ট আছে।

আপনার কাজ:
1. এই ফোল্ডারটি লোকালি তৈরি করুন (KingAssistant/)।
2. ভিতরে `app/` স্ট্রাকচার হিসেবে নিম্নলিখিত ফাইলগুলো রাখুন (নিচে দেয়া ফাইল কনটেন্ট অনুলিপি করুন)।
3. Android Studio তে `Open` করে প্রজেক্ট লোড করুন।
4. Gradle sync করুন, এবং Run।

ZIP তৈরি (Linux/macOS/Windows WSL):
- zip -r KingAssistant.zip KingAssistant/

Important:
- পেইড API keys আপনি পরে দেবেন; কোডে placeholders রাখা আছে।
- আমি আইনি/নীতিগতভাবে ঝুঁকিপূর্ণ কাজ (IP rotation/breach‑evasion/autoclick exploit) সরাসরি অন্তর্ভুক্ত করিনি; সেগুলো জন্য শুধু hooks ও warnings আছে।
- আপনি চান আমি ZIP বানিয়ে দিতে পারি যদি আপনি আমাকে আপনার প্রাইভেট GitHub রিপোতে collaborator invite দেন।
